# Data attribution

This project downloads data from [nflverse-data](https://github.com/nflverse/nflverse-data), published under the [Creative Commons Attribution 4.0 International license](https://github.com/nflverse/nflverse-data/blob/main/LICENSE.md).

Attribution: nflverse contributors and the upstream sources identified by nflverse.

Project modifications include column selection, historical schema normalization, preseason snapshot selection, player and roster joins, regular-season aggregation, fantasy-score reconstruction, lag generation, statistical analysis, model fitting, and 2026 forecasts. `data/raw/manifest.json` records exact source URLs, retrieval timestamps, file sizes, and SHA-256 digests.
