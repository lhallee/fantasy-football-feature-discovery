# Phase 1: archived baseline

Phase 1 assembled the public source data, defined the ESPN full-PPR target, compared initial model families, selected a compact five-atom offense model, and created the first complete 2026 catalog.

Phase 2 replaced this model in production. The Phase 1 retrospective used a target-year Week 1 roster proxy and therefore did not match the fixed August 9 forecast origin. Its compact result remains useful as a baseline and as a record of how the project evolved, but it no longer supplies the root models, forecasts, or generated catalog.
